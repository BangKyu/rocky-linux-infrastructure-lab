# Rocky Linux 9.8 기반 사내 업무 포털
인프라 구축 및 장애 복구

## 1. 프로젝트 소개
VMware Workstation 환경에서 Rocky Linux
9.8 기반 사내 업무 포털 인프라 구축

## 2. 프로젝트 목표
- Linux 서버 및 네트워크 구축
- Apache/PHP 사내 업무 포털
- MariaDB 데이터베이스 연동
- NFS 및 LVM 스토리지 관리
- HAProxy 웹 서버 이중화
- Prometheus/Grafana 모니터링
- Bash 백업 및 장애 복구

## 3. 실습 환경
VMware Workstation / Rocky Linux 9.8
i5-12450 / RAM 16GB

## 4. 서버 구성
LB01, WEB01, WEB02, DB01, NAS01, MON01
